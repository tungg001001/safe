# 隱私權政策 (Privacy Policy)

本隱私權政策旨在說明 **[您的產品/網站名稱]**（以下簡稱「我們」）如何收集、使用、披露及保護用戶（以下簡稱「您」）的個人資訊。當您使用我們的服務、網站或瀏覽器擴充功能時，即表示您同意本政策所述之個人資料處理方式。

---

## 1. 我們收集的資訊

我們致力於最小化數據收集，僅在提供、維護及改善服務所必需的情況下收集資訊：

* **個人識別資料**：如果您主動聯絡我們，我們可能會收集您的電子郵件地址、姓名或其他您自願提供的聯絡資訊。
* **使用數據與技術資訊**：我們可能會收集匿名的使用數據（例如：點擊次數、使用頻率、功能偏好等），以協助我們優化產品體驗。
* **Cookie 與類似技術**：如果適用，本服務可能會使用 Cookie 來記住您的設定與偏好。

*(備註：如果您的產品完全不收集任何個人資料，請將此處修改為：「我們承諾不收集、不儲存、亦不傳輸您的任何個人識別資料、瀏覽紀錄或敏感資訊。」)*

---

## 2. 資訊的使用方式

我們將收集到的資訊用於以下用途：
* 提供、操作及維護我們的服務。
* 改善、個人化及擴展我們的服務功能。
* 理解並分析您如何使用我們的服務。
* 在收到您的詢問時，進行客戶服務與技術支援。

---

## 3. 資訊的共享與披露

我們**不會**將您的個人資訊出售、交易或租賃給第三方。我們僅在以下少數情況下可能會分享您的資訊：
* **法律要求**：當法律、法規、法律程序或政府要求必須披露時。
* **保護權利**：為了保護我們、用戶或公眾的權利、財產或安全。

---

## 4. 資料安全

我們採用商業上合理的實體、電子和管理措施來保護您的資訊安全，防止未經授權的存取、修改或洩漏。然而，請注意網際網路上的傳輸或電子儲存方式並非 100% 絕對安全。

---

## 5. 第三方服務與連結

我們的服務可能包含指向第三方網站或服務的連結（例如第三方分析工具）。本隱私權政策並不適用於該等第三方。我們建議您在離開我們的服務時，局細閱讀您訪問的每個第三方網站的隱私權聲明。
