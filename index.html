職業安全衛生的四大支柱領域

以「人為本」為核心，融合工程技術、管理制度與醫學健康，達成全方位零災害目標。

職業安全 (Safety)

預防夾捲、墜落、感電、物料飛落、火災爆炸等機械設備與物理性災害。著重於機械本質安全化（光幕、防護罩、雙手按鈕）與高風險管制。

職業衛生 (Hygiene)

識別、評估與控制工作環境中之化學性（毒物、有機溶劑）、物理性（噪音、溫熱、振動）及生物性危害，推動作業環境監測與暴露分級管理。

職業健康 (Health)

實施體健檢分級管理（第1至第4級管理）、臨場健康服務、人因性危害、過勞、職場暴力與母性健康保護四大專案，確保勞工身心健康。

安衛管理 (TOSHMS)

導入 PDCA（Plan-Do-Check-Act）循環，對齊 ISO 45001 與臺灣職業安全衛生管理系統（TOSHMS），建立持續改善管理機制。

臺灣職業安全衛生核心法規要點

剖析《職業安全衛生法》雇主權責、勞工權利與重大職災通報規範

雇主法定核心責任

  • 安全防護設施：提供符合標準之機械防護具、防墜設施及防護具。
  • 安衛計畫與守則：訂定職業安全衛生管理計畫及安全衛生工作守則。
  • 教育訓練：實施法定安全衛生教育訓練（一般勞工新進至少3小時）。
  • 體健檢與管理：辦理新進員工體檢、定期健康檢查與特別危害健康作業檢查。

勞工權利與安全義務

  • 法定退避權：工作場所有立即發生危險之虞時，得自行停止作業並退避至安全場所。
  • 配合防護規定：有遵守安全衛生工作守則及正確佩戴個人防護具 (PPE) 之義務。
  • 受訓與體檢義務：不得無故拒絕參加法定安全衛生教育訓練與健康檢查。

重大職業災害通報 (法第37條)

事業單位發生下列職業災害之一時，雇主應於 8 小時內 通報勞動檢查機構：

  • 1. 發生死亡災害者。
  • 2. 發生災害之罹災人數在 3 人以上者。
  • 3. 發生災害之罹災人數在 1 人以上，需住院治療者。
  • 4. 其他經中央主管機關指定公告之災害。

危害控制階層 (Hierarchy of Controls)

風險評估後改善措施之優先順序原則，效能由高至低

01

消除 (Elimination) 最高防護效能

完全移除該項危害源。例如：停止使用具危險性的高風險製程或極毒性化學品。

源頭物理控制
02

替代 (Substitution)

以較低危害的物質或製程替代。例如：以水性塗料替代有機溶劑、降低高壓氣體壓力。

源頭替代控制
03

工程控制 (Engineering Controls)

將人員與危害源實體隔絕。例如：加裝機器防護罩、局部排氣裝置、防墜護欄、隔音罩。

工程實體隔離
04

管理控制 (Administrative Controls)

改變人員工作模式與程序。例如：建立 SOP、實施動火許可證制度、輪班降低曝露時間。

制度與流程管制
05

個人防護具 (PPE) 最後一道防線

佩戴於作業人員個體。例如：全身背負式安全帶、防塵口罩、耳朵保護具、防護面罩。

個體終端防護

局限空間作業管制 (Confined Space)

標準管制程序步驟

  1. 簽發「局限空間入場作業許可證」(PTW)。
  2. 氣體檢測：進入前測量 O2 (19.5%-23.5%)、LEL (<10%)、CO及H2S。
  3. 實施持續性強制通風（送風機風量需足夠）。
  4. 置備監護人員於入口處，保持連續通訊與監視。
  5. 準備緊急救援三腳架、救生索與正壓式空氣呼吸器。

強制配備 PPE 與設備

  • ✓ 四合一攜帶式氣體偵測器
  • ✓ 正壓式空氣呼吸器 (SCBA)
  • ✓ 全身背負式安全帶與救生繩
  • ✓ 本質安全防爆型照明與無線電

高處與高空作業管制 (Working at Heights)

標準管制程序步驟

  1. 高度 2 公尺以上防墜優先順序：工作平台 > 護欄 > 安全網 > 個人防墜。
  2. 查核天候：惡劣天氣（風速>10m/s、大雨、大霧）禁止高空作業。
  3. 確信安全母索與繫掛點強度（拉力需達 2,300 kgf 以上）。
  4. 落實「高掛低用」原則，確保安全帶掛鉤高於腰部。

強制配備 PPE 與設備

  • ✓ 全身背負式安全帶 (CNS 14253)
  • ✓ 雙大鉤含衝擊吸收繩
  • ✓ 耐衝擊防護頭盔（含頤帶）
  • ✓ 防滑安全鞋

動火作業管制 (Hot Work Operations)

標準管制程序步驟

  1. 申請動火許可證，清除周圍 10 公尺內可燃物。
  2. 排水溝、管道洞口以防火毯覆蓋密封。
  3. 現場配置兩具以上有效之 ABC 乾粉滅火器。
  4. 指派專責防火監視人，並於完工後持續監視至少 30 分鐘。

強制配備 PPE 與設備

  • ✓ 遮光面具 / 焊接護目鏡
  • ✓ 牛皮防護手套與袖套
  • ✓ 防火圍裙 / 防火服
  • ✓ 防煙塵呼吸防護具

設備檢修上鎖掛牌 (Lockout / Tagout)

標準管制程序步驟

  1. 通知與停機：告知相關操作人員，按正常程序停機。
  2. 隔離能源：切斷主電源、氣閥、水閥。
  3. 上鎖掛牌：各作業人員於隔離點施加個人安全鎖與警告牌。
  4. 洩放殘能：洩放電容殘電、管線殘壓及機械位能。
  5. 零能量驗證：測試啟動按鈕及電壓確認無殘餘能量。

強制配備 PPE 與設備

  • ✓ 個人專用安全鎖與警告標牌
  • ✓ 多孔鎖夾 (Hasp)
  • ✓ 耐電壓絕緣手套（防電弧）
  • ✓ 驗電器 / 三用電表

起重吊掛作業管制 (Crane & Rigging)

標準管制程序步驟

  1. 檢查起重機合格證及吊掛指揮人員證照。
  2. 吊掛索具（鋼索、尼龍吊帶）檢查：無斷絲、磨損過度或變形。
  3. 確定吊物重量，嚴禁超載；確認吊鉤有過捲預防與防滑舌片。
  4. 劃設吊掛作業管制區，嚴禁人員進入吊掛物下方。

強制配備 PPE 與設備

  • ✓ 具顎帶防護安全帽
  • ✓ 高可視度反光背心
  • ✓ 防滑防割手套
  • ✓ 鋼頭防砸安全鞋

勞工四大健康保護預防專案

依據《職業安全衛生法》第6條，雇主應採取必要之預防措施

1. 異常工作負荷促發疾病預防 (過勞預防)

針對輪班、夜勤、長工時及高壓力工作，評估心血管疾病風險，給予面談指導與工作調整。

• 評估工具：採用「心血管疾病發病風險評估問卷」。
• 控制手段：調整工時、限制加班、健康諮詢、安排醫護人員臨場指導。

2. 人因性危害預防 (骨骼肌肉傷害)

預防因重複性動作、不良姿勢、過度施力導致之肌肉骨骼疾病（如腰背痛、媽媽手、腕隧道症候群）。

• 評估工具：採用 KIM、KOSHA、NLE、KIM-LHC 評估工具。
• 控制手段：改善人體工學桌椅、配置自動化搬運設備、工作輪調。

3. 執行職務受不法侵害預防 (職場暴力)

預防因職務執行遭受身體肢體暴力、言語霸凌、心理騷擾或性騷擾等危害。

• 控制手段：建立通報管道、加裝監視設備、安衛與法務支援、心理輔導諮商。

4. 母性健康保護專案

針對妊娠中與分娩後未滿一年之女性勞工，保護其不受危害性化學品、物理性及粗重作業之影響。

• 控制手段：工作場所危害評估、醫師面談、適任工作調整、哺集乳室設施。
